# radar/kb —— 采集经验库

不是「帖子存档」。存档在 `radar/outbox/` 和 `radar/data/radar.db`，按天/按条。
这里是 **踩过的坑和摸出来的门道**，只记能复用的判断，供下次改代码前先读。

## 三条分类

| 目录 | 记什么 | 判据 |
|---|---|---|
| `sources/` | 每个站怎么抓、为什么这么抓、什么抓不到 | 「换个人来做，会踩同一个坑吗」 |
| `pitfalls/` | 具体报错、错误现象、根因、修法 | 「这个坑复现过一次就够」 |
| `playbook/` | 可复用的流程与判据（打分、翻译、推送） | 「能写成 step 1/2/3 的」 |

## 写法

一坑一文件，`kebab-case.md`，开头三行固定：

```
现象: （一句话，能搜到的那种）
根因: （为什么会这样）
修法: （改哪里、验证命令）
```

**不要写**：当天抓了几条、哪条拿了 5★ —— 那些在 db 和 outbox 里，写进 kb 就是重复。
